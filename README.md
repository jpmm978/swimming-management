# Integrated Swimming & Diving Management Platform (Starter Codebase)

This archive packages the application code developed across Phases 1–8 and pool-deck offline sync so you can run or build upon it in a new workspace without touching your standalone `miaa_swim_times` deployment.

## Quick Start
```bash
unzip swim_platform_starter_v2.zip
cd swim_platform_starter
pip install -r requirements.txt
pytest
streamlit run app.py
```
